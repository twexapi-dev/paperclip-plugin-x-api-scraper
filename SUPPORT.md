# Support

Use this repository's issue tracker for public support about the Paperclip plugin.

Include:

- Plugin version and install command
- Paperclip version, if known
- Tool name and minimal input that reproduces the issue
- Expected and actual behavior
- Links to [TwexAPI docs](https://docs.twexapi.io) or registry pages involved

Do not include API keys, credentials, cookies, private account data, or screenshots with private data.

For suspected vulnerabilities, follow [.github/SECURITY.md](./.github/SECURITY.md).

For TwexAPI REST behavior outside this plugin, see [docs.twexapi.io](https://docs.twexapi.io).
